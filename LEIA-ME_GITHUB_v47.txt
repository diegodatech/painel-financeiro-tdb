COMO PUBLICAR
1. Crie/abra o repositório do GitHub usado pelo painel.
2. Coloque TODO o conteúdo desta pasta na raiz publicada pelo GitHub Pages.
3. Em Settings > Pages, publique a branch usada (normalmente main / root).
4. Abra a URL do GitHub Pages.
5. No iPhone/Android, abra uma vez online para preencher o cache offline.
